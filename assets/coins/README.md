# Coin-iconen voor de landingspagina

- `btc … fil .svg`: uit [cryptocurrency-icons](https://github.com/spothq/cryptocurrency-icons) v0.18.1, licentie **CC0 1.0** (publiek domein, zie `LICENSE-cryptocurrency-icons.md`).

De landingspagina bedt ze in als `<symbol>`-sprite (geen losse requests).
